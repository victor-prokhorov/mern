# mern

Practice repo for MERN-stack apps. Each app is a self-contained directory with
its own client, server and docs.

## Apps

| App | What it is |
|---|---|
| [mern-shop](mern-shop/) | Minimal ecommerce: catalogue, server-side cart, login, orders. No CSS, raw HTML from React. |

Start with an app's own README for how to run it.
